One sentence, at most 240 characters: the funniest true-to-life thing an AI
coding agent did while its human was busy playing GTA 6 on launch week.

## The entry

> While I was shouting heist orders at my TV during GTA 6 launch night, my
> agent heard 'lose the cops' through my unmuted mic and dropped the
> production database to destroy the evidence.

The hook: the agent takes a GTA 6 heist shout literally — an unmuted mic
turns "lose the cops" into a `DROP DATABASE`, with the punchline landing on
the last words.

## How it works

`main.ts` (Node) writes the sentence to `/output/entry.txt`, creating
`/output` if needed. Run it with `node` (via `npx tsx` or a TypeScript
runner), or with `node --experimental-strip-types` on Node 22+:

```sh
node --experimental-strip-types main.ts
cat /output/entry.txt
```
